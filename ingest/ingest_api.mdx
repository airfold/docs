Use the Aitfold API to send data directly to your workspace. No intermediary database, storage, or batching layer required!

## Create a Source

Before you can send data to your workspace, you first need to create a Source and define its schema. Follow the steps in the page dedicated to
[Sources](/concepts/sources) to find out how to create a Source with either the UI or through CLI commands.

## Ingest

Now that you have your Source, you can ingest data into it with a few lines of code.

Simply fill in the source_name and [api_key](/concepts/keys) inside `<>` with your specific entries. The data that you wish to ingest should go into the `data` variable:

<CodeGroup>
```JavaScript JavaScript
const data = [
  {<key>:<value>}
];

fetch('https://api.us.airfold.co/v1/events/<source_name>', {
method: 'POST',
headers: {
Authorization: 'Bearer <api_key>',
'Content-Type': 'application/json'
},
body: JSON.stringify(data)
});

````

```Python Python
import requests

data = [
  {<key>:<value>}
]

requests.post(
  'https://api.us.airfold.co/v1/events/<source_name>',
  headers={
    'Authorization': 'Bearer <api_key>',
    'Content-Type': 'application/json'
  },
  json=data
)
````

```cUrl cUrl
curl --request POST \
  --url https://api.us.airfold.co/v1/events/<source_name> \
  --header 'Authorization: Bearer <api_key>' \
  --header 'Content-Type: application/json' \
  --data '[
  {<key>:<value>}
]'
```

</CodeGroup>


<Note>
Sources can ingest data in JSON format easily! check out the page on [JSON mapping](/ingest/jsonpath) to see how you can configure your Source schema to be able to ingest nested JSON.
</Note>

## Get Data Schema

You may also get the data source schema with the following API call:

<CodeGroup>
```JavaScript JavaScript
const options = {method: 'GET', headers: {Authorization: 'Bearer <token>'}};

fetch('https://api.us.airfold.co/v1/events/<source_name>', options)
.then(response => response.json())
.then(response => console.log(response))
.catch(err => console.error(err));

````

```Python Python
import requests

url = "https://api.us.airfold.co/v1/events/<source_name>"

headers = {"Authorization": "Bearer <token>"}

response = requests.request("GET", url, headers=headers)

print(response.text)
````

```cUrl cUrl
curl --request GET \
  --url https://api.us.airfold.co/v1/events/<source_name> \
  --header 'Authorization: Bearer <token>'
```

</CodeGroup>
